# Claude Skills Repository

A curated collection of **823 skills** harvested from popular Claude Code marketplaces (claudeskills.club & claudemarketplaces.com).

Future Claude projects can reference this repo as a skills source — point Claude at a skill's directory and it can load the `SKILL.md` plus any supporting files.

## Usage

Each skill lives in its own directory containing a `SKILL.md` (instructions + frontmatter) and optional supporting assets (scripts, references, examples).

```
<source>/<skill-name>/SKILL.md
<source>/<category>/<skill-name>/SKILL.md   (davila7 nests by category)
```

To use in a Claude project, either:
- Clone this repo and copy the desired skill folder into your project's `.claude/skills/`, or
- Reference the SKILL.md path directly when the agent needs the capability.
